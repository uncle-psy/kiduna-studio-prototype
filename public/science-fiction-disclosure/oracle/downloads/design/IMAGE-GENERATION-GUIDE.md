# Image Generation Guide

## Purpose

This workflow uses image generation as a controlled production stage while preserving originality, auditability, and system consistency.

## Invariants

- Prompt order is: card reality and evidence mode; semantic kernel; central mechanism; dominant silhouette; class border; enamel and metal; restrained accent; scale target; exclusions.
- Generate without words, logos, characters, likenesses, screenshots, or production-art references.
- A generated image is a draft until silhouette, class grammar, rights, material, and thumbnail QA pass.
- Reference images may guide material or layout only when rights and intended use are documented.

## Production Rules

- Save full prompt, negative constraints, model/tool, model version, seed if available, date, input references, and output checksum.
- Composite or retouch only through non-destructive layers and record those changes.
- Reject style drift: compare against the Visual Constitution and six neighboring masters.
- Create 2048 canonical art; never claim vector status for raster output.

## States, Scale, and Accessibility

- Meaning and class remain legible at 96, 256, 512, 1024, and 2048 pixels.
- Selected, hover, focus, disabled, and high-attention states add interface contours outside the master art; they never destructively recolor the source.
- No state, class, claim, or evidence condition depends on color alone; accessible live text supplies title, class, evidence, and safety information.

## Quality Gate

- [ ] Prompt and provenance record are complete.
- [ ] No protected or sacred imagery is reproduced without authority.
- [ ] Border, lighting, and material match the system.
- [ ] 96-pixel, grayscale, and neighbor tests pass.
- [ ] Human editorial approval is recorded.

## Rights and Provenance

Every asset must be original or used under documented permission. Record card ID, prompt or source file, creator/tool, model version where relevant, date, dimensions, color profile, source references, rights status, and checksum. Franchise-derived entries use critical symbolic abstraction and may not reproduce protected logos, characters, costumes, frames, screenshots, or production art. Sacred and community-held imagery requires context and authority; do not turn it into generic decoration.
