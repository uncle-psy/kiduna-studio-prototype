# Systems Oracle

Systems Oracle is a 360-artifact symbolic, historical, strategic, divinatory, and game-ready system about how humans coordinate intelligence, resources, labor, power, information, risk, and possibility.

It is not a deck of business vocabulary with motivational captions. Every artifact begins with a real mechanism, institution, event, object, or failure. Oracle meaning follows from structure: where state lives, who holds authority, what crosses a boundary, what accumulates, who pays, how feedback returns, and where repair is possible.

The library was selected from **1,080 evaluated candidates** across **20 domains**. The canon contains **360 artifacts**, **1601 typed relationships**, **12 historical lineages**, **12 spreads**, and **4 tested game systems**.

## Epistemic layers

Every entry separates four different claims:

1. **Documented history** — source-backed description of the artifact and period.
2. **Industry mythology** — stories a professional community tells about it.
3. **Popular interpretation** — simplified public meaning.
4. **Oracle synthesis** — this project’s authored structural and symbolic reading.

Never quote an oracle synthesis as a historical actor’s stated intent.

## Quick start

- Run `npm run build` to regenerate and validate.
- Run `npm run serve` and open http://127.0.0.1:8766.
- Read [How to Use](manual/HOW-TO-USE.md), [Divination](manual/DIVINATION.md), [Spreads](manual/SPREADS.md), or [Games](manual/GAMES.md).
