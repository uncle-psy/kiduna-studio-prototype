## Generated specifically for this Site

- `og.png` — social sharing artwork generated once for this UI-plan Site. It is not a Kiduna logo or a game identity asset.

Final generation prompt:

> An elegant abstract social card representing three clearly nested Realms in one continuous intelligent Field; warm espresso ground; organic enamel rings using Kiduna sky, cream, and gold with a midnight-navy inner Realm; fine cloisonné relational filaments; restrained light; no people, faces, logos, text, glossy AI aesthetic, glassmorphism, or lens flare.

## Usage

Do not recolor logos casually. Action icons use `currentColor` where supported. Keep the R&R assets inside the R&R Realm presentation. Refer to the original archive documentation for license or redistribution terms; this package asserts no new rights.
