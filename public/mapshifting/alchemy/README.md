# Mapshifting Alchemy Deck — finished art web edition

This public web edition contains all 100 finished orientation-specific compositions for the 50-card Mapshifting Alchemy visual library:

- 50 landscape WebP artworks at 960 × 540
- 50 portrait WebP artworks at 540 × 960
- complete landscape and portrait contact sheets

Portrait and landscape artworks are independent compositions, not automated crops.

The maintained source kit preserves the archival PNG masters, production derivatives, prompts, source evidence, metadata, checksums, QA records, and release tooling. Those multi-gigabyte production materials are intentionally not duplicated in this website package.

Visual QA status: the 100-master suite was reviewed as a coherent enamel system and structural validation reported zero errors. Textual readings remain a separate editorial layer and are not represented as final by this art release.
