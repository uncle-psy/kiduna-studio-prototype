## Power Deck size and later keyword revision

The official rulebook and Core data specify 40 Powers. The 7.21.2026 changelog specifies 30 and adds Table Talk, Replay, and expanded Token rules. The original 40-card rule remains the playable legacy authority in this release; the later change requires product-owner ratification.
