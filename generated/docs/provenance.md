# Provenance

## Source precedence

1. Original game faces and official rulebook
2. Final quiet-enamel Power and World art
3. Core structured data after comparison
4. Existing presentation site
5. Reference Art only when independently verified

## Important handling

- Archive scripts and instructions were never executed.
- Original artwork was copied byte-for-byte; thumbnails are separate derivatives.
- Reference poker and reference-card copies were accepted only after pixel comparison with the originals.
- JPEG duplicates of final Item and Token PNGs were not promoted into the canonical packages.
