# Royals & Rogues Game Library

The production source for the Royals & Rogues game library at [kiduna.design](https://www.kiduna.design).

The site connects the original playable game, final quiet-enamel artwork, digital card copy, rules, provenance, validation reports, and versioned developer packages.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Large downloadable kits are published as assets on the `royals-and-rogues-v3.0.0` GitHub release. The deployable site keeps web-sized previews and structured records in the repository.
